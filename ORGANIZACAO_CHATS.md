# ORGANIZAÇÃO DOS CHATS — Projeto Analista Registro e Redação

Atualizado em: **22/09/2026**

## Princípio

Os chats são **interfaces de trabalho**, não a fonte final de verdade. O GitHub `pmartins87/Analista` continua sendo a fonte de verdade do projeto.

Cada chat deve ter uma função estável. A regra é organizar por **domínio de trabalho**, não por dia, aula ou PDF.

Não abrir um chat novo para cada sessão de estudo. Só criar continuação quando um chat ficar grande demais ou tecnicamente inconveniente; nesse caso, o novo chat deve herdar o papel do anterior e consultar a fonte de verdade no GitHub.

---

## 00 — PAINEL / ROADMAP / ORGANIZAÇÃO

**Função:** coordenação do projeto.

Usar para:
- “o que eu estudo agora?”;
- reportar conclusão de passos;
- avançar o roadmap;
- decidir prioridades;
- reorganizar carga/tempo;
- discutir estratégia;
- acompanhar edital e mudanças oficiais;
- revisar métricas;
- decidir se um tópico precisa de remediação;
- decidir quando um material do Gran deve ou não ser usado.

Não usar como local principal para dúvidas de conteúdo de Português, RICD, RCCN etc.

**Este chat atual exerce essa função.**

## 02 — RICD

**Função:** Regimento Interno da Câmara dos Deputados.

Usar para:
- leitura artigo por artigo;
- literalidade;
- interpretação;
- questões;
- dúvidas de competência, prazo, composição, procedimento e exceção;
- cartões derivados do RICD.

Regra: texto oficial vigente prevalece sobre curso, resumo e memória.

- dúvidas;

- comissões mistas;

## 04 — REVISÃO TEXTUAL / REDAÇÃO

**Função:** treino de revisão, correção e produção textual.

Usar para:
- exercícios de revisão;
- textos parlamentares;
- correção justificada;
- falsos positivos;
- erros não detectados;
- discursiva, se confirmada;
- critérios de estilo/redação oficial relevantes à prova.

Não misturar com gramática abstrata quando a dúvida puder ser resolvida no chat de Português.

---

## 05 — SIMULADOS / DIAGNÓSTICO

**Função:** provas completas ou baterias multidisciplinares.

Usar para:
- simulados mistos;
- baseline;

- desempenho líquido;
- estratégia de prova;
- tempo;
- identificação de gargalos.

Regra de roteamento:

- a correção conceitual profunda de um erro volta para o chat da disciplina correspondente e para o arquivo canônico adequado.

Fonte de verdade: `ANKI.md`.

## Chats que NÃO devem ser criados ainda

Não criar, por enquanto, chats permanentes para:
- Inglês;
- Raciocínio Lógico;
- Informática e Dados;
- Inteligência Emocional;
- Direito Administrativo completo;
- Direito Constitucional completo.

Motivo: essas matérias ainda não foram confirmadas no edital específico. Diagnósticos pontuais podem ser feitos no chat de Simulados/Diagnóstico. Se o G1 confirmar a disciplina, criar chat dedicado apenas quando o volume justificar.

---

## Regra para dúvidas que surgem “no lugar errado”

Se uma dúvida de Português for enviada ao Painel, ela pode ser respondida para não interromper o estudo, mas deve ser tratada como **roteamento incorreto**.

A partir daí:
1. registrar conhecimento relevante no arquivo canônico da matéria;
2. continuar o aprofundamento no chat correto;
3. não transformar o Painel em caderno de conteúdo.

Não existe necessidade de apagar a mensagem nem reiniciar trabalho já feito.

---

## Regra para cartões Anki

- dúvida/erro nasce no chat da matéria;
- explicação é validada ali;
- o conteúdo de alto valor é marcado como candidato;
- o padrão e exportação são consolidados no sistema Anki;
- não duplicar conhecimento em múltiplos chats só para “organizar”.

---

## Regra para continuidade

Quando um chat ficar longo:
1. criar “<MATÉRIA> — Continuação 2”;
2. informar que é continuação do chat anterior;
3. consultar os arquivos canônicos do GitHub antes de continuar;
4. manter exatamente a mesma função;
5. não criar nova estratégia apenas porque o chat mudou.

---

## Mapa rápido de roteamento

- **O que estudo agora?** → Painel
- **Terminei O0.02; resultado...** → Painel
- **O que é paralelismo sintático?** → Português
- **Corrija as questões 14–26 de Português** → Português
- **Leia/explique o art. X do RICD** → RICD
- **Como funciona o veto no RCCN?** → RCCN
- **Corrija este texto parlamentar** → Revisão textual
- **Fiz um simulado misto; analise meus erros** → Simulados/Diagnóstico
- **Como configuro FSRS/tags/importação?** → Anki
- **Crie/avalie fraseogramas** → Taquigrafia
- **Saiu o edital; o que muda?** → Painel

---

## Fonte de verdade e sincronização

O conteúdo útil não pode ficar preso apenas em chats.

Quando uma conversa gerar:
- decisão estratégica → `ROADMAP.md` / `ROADMAP_OPERACIONAL_APROVACAO.md`;
- estado atual → `STATUS.md`;
- rotina → `PLANO_ESTUDOS_REVISOES.md`;
- Português → arquivos de Português;
- Anki → `ANKI.md`;
- taquigrafia → `TAQUIGRAFIA_FRASEOGRAMAS.md`;
- nova fonte oficial → `FONTES.md`.

O Painel deve sempre poder reconstruir o estado do projeto lendo esses arquivos.
